# WiFiTIC pour Home Assistant

Intégration personnalisée Home Assistant pour les compteurs Linky équipés d’un module **WiFiTIC CARTELECTRONIC**.

## Fonctionnalités

- Lecture des informations du compteur via MQTT
- Suivi du soutirage et de l’injection réseau
- Index par périodes tarifaires
- Importation et raccordement des historiques énergétiques REST aux statistiques natives Home Assistant
- Compatibilité avec le tableau de bord Énergie

## Version

La version initiale prévue est **0.0.1**, issue de la version de travail 1.0.45.

> Le code de l’intégration sera ajouté au dépôt après validation du transfert complet des fichiers. Ce dépôt n’est pas encore installable via HACS.
